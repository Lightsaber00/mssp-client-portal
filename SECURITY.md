# Security Policy

## Supported versions

This repository is currently a portfolio and architecture demonstration project.
No production releases are maintained at this stage.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you identify a potential security issue in this repository, please contact the repository owner through a private communication channel listed in the GitHub profile.

Please include the following information where possible:
- a short description of the issue
- affected file or component
- reproduction steps
- expected versus actual behavior
- potential impact
- screenshots, logs, or proof-of-concept material if relevant

## Disclosure policy

Please avoid public disclosure until the issue has been reviewed.

This project follows responsible disclosure principles:
- report privately first
- provide enough detail for validation
- avoid unnecessary exploitation
- allow time for review and remediation

## Scope note

This repository is intended for portfolio demonstration purposes and does not expose a live production service.
