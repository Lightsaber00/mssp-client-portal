# Contributing

Thank you for your interest in this project.

This repository is currently maintained as a portfolio and architecture demonstration project. Contributions are not the primary focus at this stage, but constructive suggestions are welcome.

## How to contribute

If you want to suggest an improvement:

1. Open an issue with a clear title
2. Describe the problem or improvement
3. Keep suggestions focused and practical
4. Avoid submitting secrets, credentials, or sensitive data

## Pull requests

Pull requests should be small, clear, and aligned with the project scope.

Good pull requests should:
- improve clarity
- improve documentation
- improve structure
- avoid unrelated changes

## Security note

Do not submit vulnerabilities through public issues.
Please use the guidance in `SECURITY.md`.
